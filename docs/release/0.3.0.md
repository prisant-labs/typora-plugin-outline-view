# Outline View 0.3.0

**Release date:** September 21, 2026

Make long outlines easier to scan with optional hierarchy guides, alternating
row colors, and tools for keeping the current section in view. New appearance
options keep conservative defaults, and existing heading styles are preserved.

## Appearance and navigation

- Choose the collapse marker: current triangle, small bullet, line arrow,
  open/closed folder, or no icon. Labels sit closer to the collapse target.
- Enable vertical guides with Quiet or Clear strength. Guides extend to the
  bottom of their branch containers, including wrapped headings.
- Enable Alternating row colors with independent Row A and Row B colors. The
  sequence follows visible headings as branches expand and collapse.
- Choose Theme, Plugin default, or Custom colors for guides and both row colors.
  Custom colors offer Light/Dark swatches, opacity, and an option to use the
  Light color in both themes.
- Separate top-level sections with extra space or a faint divider, emphasize
  the active heading's ancestors, or show a clickable current-path bar.
- Focus current branch shows the current heading, its ancestors, and its subtree.

## Clearer settings

Related settings appear indented beneath their enable option and hide when
disabled. Re-enabling restores saved choices. Custom color editors sit below
their dropdowns, with consistent layouts for guide and alternating row colors.
The live preview and [offline settings prototype](../prototype/settings.html)
use the production components.

## Heading-label fix

Headings such as `**Next steps**` now display as `Next steps` in the outline.
The parser excludes Typora's Markdown marker and source-metadata elements while
retaining readable inline content, literal punctuation, and navigation targets.
Document content is unchanged.

Hover feedback remains visible over alternating row colors. Auto-scroll follows
the active row immediately after revealing a collapsed branch or changing the
focused branch, while respecting the Auto-scroll outline setting.

## Upgrade and compatibility

Existing settings are retained. New guides, alternating row colors, and path
aids start disabled; the triangle remains the default collapse icon. Choose
the new options in Community Plugins > Outline View settings.

Requires Community Plugin 2.10.21 or later, with Windows and macOS as supported
platforms. The manifest's Typora 1.4.0 minimum remains independently uncertified;
Linux runtime support is not advertised. Source mode does not provide live
outline parsing. Third-party themes can affect appearance.

Install through Marketplace once its metadata refreshes, or follow the
[manual installation instructions](../../README.md#manual-installation-or-candidate-testing)
using [0.3.0's plugin.zip](https://github.com/prisant-labs/typora-plugin-outline-view/releases/download/0.3.0/plugin.zip),
not GitHub's source archive. The existing marketplace registration points to this
repository; version updates do not require a new registry submission.

## Validation

On September 21, 2026, the maintainer reported that the development candidate
looked good in both macOS and Windows after testing the appearance changes and
heading-label fix. This is maintainer-reported native validation, not an
agent-executed test. Exact platform versions, themes, and per-case observations
were not supplied. The candidate still carried version 0.2.1; its checksum is
recorded in the [native validation record](NATIVE-CHECKLIST.md).

Automated tests, typechecking, generated-prototype freshness, and package-content
validation complement the native report. Release preparation changes the version
and documentation; any subsequent code fixes have their own automated coverage.
Two pre-merge fixes for hover precedence and first-event auto-scroll were added
after the native report and verified with automated regression checks.
