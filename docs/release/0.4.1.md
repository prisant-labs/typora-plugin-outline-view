# Outline View 0.4.1

**Release date:** October 29, 2026

This patch fixes the thick line on the left edge of the outline dock.

**A single line on the dock's left edge.** Community Plugin Core draws a 1px
left border on the right dock. It also draws a 1px left border on the tab group
inside the dock. In the editor area, Core hides the second line with a negative
margin, but it does not do so inside the dock. The two lines sat side by side
and read as one 2px line. Core 2.10.70 colors these borders from the operating
system's dark mode rather than from the Typora theme. With Windows in dark mode
and a light Typora theme, the double line was dark and easy to see. Outline View
now removes the tab group's border only when the group holds the outline, so the
dock's own 1px border remains and other dock panes are unchanged.

**Where the dock toggle lives.** The button that expands and collapses the right
dock belongs to Community Plugin Core, which places it in Typora's status bar
beside the word count. Outline View only gives it the outline icon and tooltip.
When the status bar is hidden, the button is hidden with it. The command
**Outline View: Toggle** in the command palette works either way.

There are no settings migrations. Community Plugin 2.10.21 or later remains
required. Windows and macOS remain the advertised platforms; Linux runtime
support is not claimed. The manifest's Typora 1.4.0 minimum remains
independently uncertified.

## Validation

The maintainer authorized publication on October 29, 2026, before native
testing of this build. The maintainer also waived the recorded gate that called
for the native Update pill steps before this release. 0.4.1 is therefore the
first release that users of 0.4.0 receive through the pill, and that path has
not been tested in Typora. If the pill's update fails, update Outline View under
**Installed Plugins** in Community Plugin settings instead. See the
[native validation record](NATIVE-CHECKLIST.md).

The border diagnosis comes from a Windows screenshot taken by the maintainer and
from reading the CSS of the installed Core 2.10.70 and the pinned Core 2.10.21.
Both versions draw both borders.

Automated coverage includes 277 tests across 30 files, two Chromium layout tests,
typecheck, prototype freshness, package validation, dependency audit, and
required Windows/Linux CI. Browser and CI results are separate from native
Typora testing.

The dependency audit required patched test and build tooling: Vitest 4.1.12,
Vite 8.3.5, `source-map-js` 1.2.2, and `serialize-javascript` 7.1.4. Vite is
now a direct development dependency, because pnpm kept Vitest's automatically
installed Vite peer at a vulnerable version. These packages are used only while
testing and building, and they are not part of the plugin archive.
