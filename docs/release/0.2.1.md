# Outline View 0.2.1

**Release date:** September 18, 2026

Keep Files visible while navigating an independent, synchronized outline in
Typora's right dock. This is the first public GitHub release of Outline View.
Marketplace enrollment is pending; use the manual installation below.

## Highlights

- **Keep your place:** The current heading has a theme-derived fill and outline
  that stays visible without changing your selected heading typography or color.
- **Focus on the levels you need:** Choose ranges such as H2-H4 with dragging,
  clicks, or keyboard controls, and choose the selector's appearance.
- **Style without leaving settings:** Preview per-level typography and color
  changes immediately using your document or a full sample outline.

## New features

- Live H1-H6 outline, click navigation, active-heading following, and branch
  expand/collapse with session state.
- Two-endpoint heading ranges with drag, click and keyboard input; Rail,
  Enclosure and Bracket styles; optional labels, grayscale, and hide control.
- Per-heading size (50-250%), bold/italic/underline, ALL CAPS/Small Caps,
  theme/custom color, and resets. Markdown contents are unchanged.
- A current-state wrap toggle beside the settings gear, and a full 57-heading
  prefixed sample shared by settings and the offline prototype.
- A maintained [offline settings prototype](../prototype/settings.html) generated
  from production UI, with CI enforcement against stale output.

## Improvements

- Settings controls stay close to their labels, with bordered dropdowns and a
  contained Live outline view. Sticky section links make longer settings easier to navigate.
- The wider preview uses available vertical space, with a compact source/sample
  row. Narrow settings windows retain a compact preview.
- Emphasis buttons have clear selected/unselected states. Custom color swatches
  appear only when needed, and settings changes never rewrite Markdown.

## Bug fixes

- Fixed active tracking that could remain stuck on the first heading while scrolling.
- Fixed long unwrapped labels expanding or shifting the dock, toolbar, or padding.
- Fixed outlines not filling the available dock width with short or long documents.
- Removed stray selector-endpoint marks and emphasis-button corner badges.
- Restored dropdown borders and preview bottom clearance.

## Install or upgrade

Requires Community Plugin 2.10.21 or later; 2.10.21 is the test baseline.
The manifest's Typora 1.4.0 minimum is not independently certified. Windows and
macOS are supported platforms; Linux runtime support is not advertised.

Download `plugin.zip` from the
[0.2.1 release](https://github.com/prisant-labs/typora-plugin-outline-view/releases/tag/0.2.1),
not GitHub's automatic source-code ZIP. Follow
[manual installation](../../README.md#manual-installation-or-candidate-testing).
Back up the existing plugin folder, close Typora, and replace its contents with
`plugin.zip`. Legacy Theme/null B/I/U values become Off; explicit On/Off choices
are retained. Theme/custom colors are unchanged. Per-document ranges and
collapse state remain session-only. Back up settings before downgrading.

## Known issues and validation

The maintainer confirmed final native Windows/macOS validation complete on
2026-09-18 for the released archive. This is maintainer-reported signoff, separate
from automated verification; detailed OS/application/theme versions were not
provided with the confirmation. See [the validation record](NATIVE-CHECKLIST.md).
Source mode does not provide live outline parsing;
return to rendered mode to resume navigation. Third-party themes may differ
from the prototype's sample themes.

Automated tests, typechecking, prototype freshness, package validation and
Windows/Linux CI cover the build and components, not native OS compatibility.
Marketplace installation is unavailable until the registry submission is accepted.

The ZIP contains the MIT license and third-party notices. A SHA-256 checksum
accompanies the release asset. The historical `0.2.0` tag is unchanged.
