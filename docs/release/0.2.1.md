# Outline View 0.2.1 candidate

Keep Files visible while navigating an independent, synchronized outline in
Typora's right dock. This candidate includes the complete heading-navigation
experience and the settings polish intended for the first public release.

## Included

- Live H1-H6 outline, click navigation, active-heading following, and branch
  expand/collapse with session state.
- Two-endpoint heading ranges with drag, click and keyboard input; Rail,
  Enclosure and Bracket styles; optional labels, grayscale, and hide control.
- Per-heading size (50-250%), bold/italic/underline, ALL CAPS/Small Caps,
  theme/custom color, and resets. Markdown contents are unchanged.
- Live settings preview with compact controls, bordered dropdowns/preview,
  binary emphasis toggles, conditional swatches, and sticky section navigation.
  The Live outline view is 50px wider with a compact source/sample row and bottom
  clearance. Narrow settings retain a compact sticky preview.
- No-wrap dock containment and vertical-only active following keep toolbar,
  selector and heading padding stable with long labels.
- A maintained [offline settings prototype](../prototype/settings.html) generated
  from production UI, with CI enforcement against stale output.
- MIT/third-party notices in the ZIP, exact artifact/version validation,
  Windows/Linux CI, and updated build/test dependencies.

## Install or upgrade

Requires Community Plugin 2.10.21 or later; 2.10.21 is the test baseline.
The manifest's Typora 1.4.0 minimum is not independently certified. Windows and
macOS are candidate platforms; Linux runtime support is not advertised.

Follow [manual installation](../../README.md#manual-installation-or-candidate-testing).
Back up the existing plugin folder, close Typora, and replace its contents with
`plugin.zip`. Legacy Theme/null B/I/U values become Off; explicit On/Off choices
are retained. Theme/custom colors are unchanged. Per-document ranges and
collapse state remain session-only. Back up settings before downgrading.

## Validation and publication boundary

Automated tests, browser prototype checks, and CI do not establish native OS
compatibility. Complete [the native checklist](NATIVE-CHECKLIST.md) on the final
archive before publishing. Source mode does not provide live outline parsing;
return to rendered mode to resume navigation. Third-party themes may differ
from the prototype's sample themes.

This document is release-note preparation, not a claim that a GitHub Release or
marketplace listing exists. Follow [the release runbook](../MARKETPLACE-RELEASE.md)
for explicit visibility/publication approval and upstream registry submission.
Do not move or overwrite the `0.2.0` tag.

Selectable disclosure icons and optional hierarchy guides remain backlog items.
