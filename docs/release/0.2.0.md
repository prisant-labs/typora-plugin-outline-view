# Outline View 0.2.0

## Scope

The approved heading-selector and appearance iteration. No Markdown rewriting,
heading reordering, private editor-model APIs, or Node-native runtime dependency.

- Two endpoints with direct dragging, click-to-arm, keyboard controls, equal
  ranges, bounded movement, and per-document session memory.
- Rail / Enclosure / Bracket, H1-H6 labels or dots, theme / grayscale, show / hide.
- Independent H1-H6 size (50-250%, 5% steps), emphasis, case, theme/custom color,
  reset controls, and shared live preview.
- SVG settings and existing dock-toggle icons; framework-created dock placement
  and fallback F1 commands are unchanged.

## Validation boundary

Automated coverage includes legacy settings normalization, invalid input,
range interaction and cancellation, per-file state, noncompounding heading
styles, preview updates, reset, and cleanup. Browser component smoke checks
exercise production DOM/CSS with a lightweight host adapter, not the native
Typora application. Production build and archive checks are separate gates.

The earlier Windows baseline and user-confirmed macOS baseline do not substitute
for native testing of this version. Before marketplace publication, install the
packaged build on Windows and macOS, verify the new controls/settings, and
recheck the Mac toggle icon. Linux remains unsupported in the manifest.

## Release artifacts

- Tag: `0.2.0` on the verified integration commit.
- `pnpm run pack` produces `plugin.zip` and the byte-identical
  `plugin_typora-outline-view.zip`.
- Archive root: `main.js`, `style.css`, `manifest.json` only.
- Repository visibility changes, a public GitHub Release, marketplace-list PR,
  and upstream acceptance are separate from creating this version tag.

## Settings compatibility

Existing settings remain valid. Missing new keys use defaults; malformed style
values are normalized. Defaults remain H1-H6, comfortable density, medium
indentation, wrapping on, and auto-open off. New default selector is Rail with
labels and theme colors; heading style defaults are 100%, theme emphasis/color,
and normal case.

The active heading uses the theme accent and weight 600 even when a level has
custom color/weight, preserving the existing navigation cue.
