# Outline View 0.4.0

**Release date:** October 2, 2026

This release lets Outline View tell you when a newer version is available, and
lets you update it without leaving the outline.

**An update pill.** When Community Plugin Core's Plugin Marketplace offers a
newer Outline View, a small **↑ Update** pill appears in the outline toolbar and
beside **Installed** on the settings page. In a narrow dock, the pill shows only
the arrow and the version. Click either pill to review the update, then choose
**Update**. Community Plugin Core downloads the new version and reloads Outline
View in that window. Your Outline View settings are kept, and other Typora
windows keep the old version until they restart. If the download fails,
reinstall Outline View from the Plugin Marketplace; your settings are still kept.

**This release cannot announce itself.** The pill appears only in versions that
have it, so you get 0.4.0 the usual way: open Community Plugin settings and
update Outline View under **Installed Plugins**. From 0.4.0 on, later releases
appear as a pill.

**A new Updates setting.** "Check for updates automatically" is on by default.
At most once a day, when the outline or its settings page opens, Outline View
asks Community Plugin Core to check the Plugin Marketplace. Core downloads the
Marketplace's public lists from GitHub. With the check off, Outline View makes
no update requests of its own. A pill can still appear when Core already holds
newer Marketplace data, for example after you open Core's **Installed Plugins**
tab.

**Settings masthead changes.** The masthead still shows the latest GitHub
release and its date, but it now asks GitHub only while the check is on.
"Update available" now comes from the Plugin Marketplace, which Core installs
from. A newer GitHub release that the Marketplace has not picked up yet shows as
**Newer release**; the Marketplace refreshes once a day. With the check off, the
status reads **Not checked**. The "Update available" status now keeps full text
contrast in Typora's default theme.

**Privacy.** Outline View collects no telemetry and sends nothing about you or
your files. Network requests happen only through Community Plugin Core: the
daily Marketplace check and the settings page's release lookup while the check
is on, and a download when you confirm an update. The update-check record is
kept in Typora's browser storage, separate from your settings, so older Outline
View versions read their settings unchanged.

There are no settings migrations. Community Plugin 2.10.21 or later remains
required. Windows and macOS remain the advertised platforms; Linux runtime
support is not claimed. The manifest's Typora 1.4.0 minimum remains
independently uncertified.

## Validation

The maintainer authorized publication on October 2, 2026, before native testing
of this build. Native confirmation of 0.4.0, and of 0.3.2's macOS navigation
fixes, is pending on macOS and Windows. See the
[native validation record](NATIVE-CHECKLIST.md).

Native testing of the pill is easiest now. A test build that claims an older
version, such as 0.3.9, is offered 0.4.0 itself, so the whole update path runs
against a real release. Run those steps before the next release, because that
release is the first one users will receive through the pill. The steps are in
the [test plan](../TEST-PLAN.md#native-steps).

Automated coverage includes 276 tests across 30 files, two Chromium layout tests,
typecheck, prototype freshness, package validation, dependency audit, and
required Windows/Linux CI. The update tests run against a fake Community Plugin
Core and an in-memory IndexedDB. The Core behavior they rely on was read from the
pinned Core 2.10.21 source and is recorded in
[RESEARCH-NOTES.md](../RESEARCH-NOTES.md#plugin-marketplace-and-updates).
Browser and CI results are separate from native Typora testing.

The new code adds about 20 KB to `main.js`, mostly helper code for compiling
asynchronous functions to ES5. The plugin archive contents are unchanged:
`main.js`, `manifest.json`, `style.css`, `LICENSE.md`, and
`THIRD-PARTY-NOTICES.md`.

## Installation

Update through Marketplace after its metadata refreshes, or follow the
[manual installation instructions](../../README.md#manual-installation-or-candidate-testing)
using [0.4.0's plugin.zip](https://github.com/prisant-labs/typora-plugin-outline-view/releases/download/0.4.0/plugin.zip).
The existing marketplace entry already points to this repository, so this update
does not require another registry PR. GitHub's source archive is not a plugin package.
