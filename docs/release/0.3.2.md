# Outline View 0.3.2

**Release date:** September 30, 2026

This patch fixes two outline problems that the maintainer reported on macOS.

**Rows no longer disappear while a heading shows its source.** Typora's
preference Markdown → Live Rendering → "Display source for simple blocks
(including headings, etc.) on focus" is off by default. When it is on, Typora
replaces the heading under the caret with a paragraph that shows its `#`
markers. Outline View recognized only `h1`-`h6` elements, so that heading's row
disappeared until the caret left it. Outline View now reads the source form
too. The row keeps its label, without `#` markers, and keeps its collapse and
active state. The preference, not the operating system, triggers this, so it
also applied on Windows.

**Outline clicks scroll the editor directly.** In 0.3.1, a click started a
smooth scroll and then focused the editor. On macOS, the document stopped moving
once the caret had been placed in it, although clicks worked right after a file
loaded. A console diagnostic showed the target heading was present and the
scroll was requested, but the editor's scroll position never changed. The most
likely cause is that focusing the editor returned to the caret and cancelled the
smooth scroll. Navigation now focuses the editor first, only when focus is
elsewhere. It then sets the editor's scroll position so the heading's top meets
the top of the editor. It also follows a heading that Typora has replaced, by
its ID.

**Visible change on every platform:** outline navigation now jumps to the
heading instantly instead of gliding to it. Navigation still does not move the
caret into the heading.

There are no settings migrations. Community Plugin 2.10.21 or later remains
required. Windows and macOS remain the advertised platforms; Linux runtime
support is not claimed. The manifest's Typora 1.4.0 minimum remains
independently uncertified.

## Validation

The maintainer authorized publication on September 30, 2026, before native
testing of this build. On the same day, a read-only console diagnostic in the
maintainer's macOS Typora identified both causes in 0.3.1; that diagnostic
examined 0.3.1, not this build. Native confirmation of 0.3.2 on macOS and
Windows is pending. See the [native validation record](NATIVE-CHECKLIST.md).
If native testing shows that the scroll still fails on macOS, a follow-up patch
will address it.

Automated coverage includes 213 tests across 26 files, two Chromium layout tests,
typecheck, prototype freshness, package validation, dependency audit, and required
Windows/Linux CI. The new tests use heading-source markup captured from Typora on
macOS, with synthetic text. Browser and CI results are separate from native
Typora testing.

The dependency audit required patched build tooling: `brace-expansion` 2.1.7 and
`serialize-javascript` 7.1.2. These packages are used only while building and are
not part of the plugin archive.
