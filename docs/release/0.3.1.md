# Outline View 0.3.1 - release candidate

**Status:** Not tagged or published. Release date pending native validation and
maintainer approval.

This patch makes plugin identity and update context visible without taking space
from the settings controls. The compact masthead appears above section navigation
and shows author, installed version, latest published version, last release date,
GitHub, and a small Local folder button, in that order. A middle dot separates
the link from the button.

Local folder opens the installed plugin directory through the Community Plugin
app API. Current and Last updated come from the latest published GitHub release;
when that lookup is unavailable, the masthead says so and settings still work.
The header does not include a plugin description, release-notes link, or issue
link. The [offline settings reference](../prototype/settings.html) uses simulated
release and folder services and is not a live update check.

There are no settings migrations or outline behavior changes. Community Plugin
2.10.21 or later remains required. Windows and macOS remain the advertised
platforms; Linux runtime support is not claimed. The manifest's Typora 1.4.0
minimum remains independently uncertified.

Automated tests, typecheck, prototype freshness, package validation, dependency
audit, and required Windows/Linux CI are release-preparation checks. Native
Typora review of the header, links, Local folder action, narrow layout, and
light/dark contrast is still pending. Record that separately using the
[test plan](../TEST-PLAN.md#settings-masthead-candidate) before publication.

The marketplace entry already points to this repository, so an ordinary version
update does not require another registry PR. When approved, publish the exact
validated `plugin.zip` under an annotated `0.3.1` tag, following the
[release runbook](../MARKETPLACE-RELEASE.md). GitHub's source archive is not a
plugin package.
